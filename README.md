# 認知照護導航

公開網站：https://yht5582-source.github.io/dementia-evaluation/

原始碼：https://github.com/yht5582-source/dementia-evaluation

繁體中文互動網站，供民眾／家屬整理就醫資訊及醫療人員整理鑑別證據。**臨床決策輔助，不能取代醫師判斷。**

## 直接使用

可使用「失智症互動評估.html」單一檔案；在一般瀏覽器開啟即可使用，無需安裝。

多檔版本為 `index.html`。請保留同資料夾中的 `style.css`、`data.js`、`engine.js`、`app.js`。網站不依賴外部字型、套件或網路；原始指引連結需網路。

也可在此資料夾啟動靜態網站服務後，於瀏覽器開啟：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

瀏覽 `http://127.0.0.1:8765`。公開版由 GitHub Pages 提供；本機版可離線使用。

## 操作

1. 選擇民眾與家屬／醫療人員模式，先回答四項安全檢核。
2. 整理認知下降、獨立生活功能及知情者病史；醫療人員可補入正式認知與其他病因評估。
3. 整理 AD、DLB、bvFTD、血管性病因線索，並保留 PDD、PPA、iNPH 等轉介方向；醫療人員模式可記錄可逆／共存因素檢查（B12、甲狀腺、代謝、血球、結構影像等）結果。
4. 評估完整 Lancet 2024 十四項危險因子，填寫證據／計畫、負責角色與追蹤日期。
5. 在評估報告列印或選擇「存成 PDF」；可主動下載 JSON 評估檔，下次匯入續填。

## 資料與隱私

- 資料只在頁面記憶體，不上傳、不自動儲存；重新整理或關閉即清除。請主動下載後自行保管。
- 不蒐集姓名、病歷號；自由文字請去識別化。下載檔與 PDF 仍可能含敏感資料，須依院內規範保管。
- 匯入先驗證結構／大小／狀態／文字長度，僅接受已知欄位；匯入前確認取代。輸出文字 HTML 跳脫。
- 切換為民眾模式時，已填的專業欄位保留於記憶體與下載檔，但不參與民眾模式的判讀。重新切回醫療模式可查看。清除按鈕會清除所有模式資料。

## 臨床範圍

- 此為原創病史整理問卷，非正式量表，不重製 MoCA／MMSE／AD8，不宣稱診斷效能。
- 不計算個人失智機率，不由危險因子數量給風險分級，不依機率排序病因。
- 未完成安全問題、急性警訊或快速進展時，不顯示亞型鑑別判讀。
- 「支持線索」指使用者輸入，不代表醫師已確認。沒有資料保留待補；陰性回答不能單獨排除病因。
- AD 生物標記與症候群分開；一般血液或 APOE 不視為 AD 核心標記。不建議無症狀常規 AD 生物標記篩檢。
- DLB／bvFTD 的條件為部分共識摘要；本網站未實作正式 possible／probable／definite 診斷分類。
- PDD 只提醒病史時間關係，未實作完整 PDD 診斷條件；PPA 不判定亞型；iNPH 不依三徵確診。未涵蓋所有少見病因。
- Lancet 2024 的約 45% 為人口可歸因比例，非個人降低風險承諾；既往教育／外傷不可回溯更改。
- **尚未經臨床診斷效能驗證；公開臨床使用前需神經／老年醫學專業內容審查與院內流程確認。**

原始來源、年份與規則對應詳見 `docs/clinical-sources.md` 及網站「準則與限制」。查核日期 2026-10-11。

## 靜態部署

GitHub Pages 使用 `.github/workflows/pages.yml`：推送到 `main` 時先檢查語法、執行 22 項規則測試，再由 `scripts/build_site.py` 打包網站並部署。Actions 固定到已查核的 commit SHA。

網站執行時無需 Node.js；Node.js 只用於部署前測試。發布內容使用明確的檔案清單，不包含測試、Git 資料、評估 JSON 或 PDF。`python3 scripts/build_site.py` 可同步產生最新單檔 HTML 與 `_site` 發布資料夾。

也適用院內靜態網站或 GitHub Pages。將五個網站檔放在部署根目錄即可；不需後端、Node.js 或建置步驟。請勿把評估 JSON／PDF 放入公開網站或儲存庫。公開使用前應先審查醫療內容與院方要求。

## 驗證

純規則測試：

```sh
node tests/rules.test.cjs
```

測試涵蓋安全優先、資料缺口、MCI／SCD／功能下降界線、專業欄位隔離、混合線索、非特異線索不單獨觸發病因、PD 時序、可逆因素檢查、來源索引及完整 14 因子。瀏覽器驗證記錄見 `docs/verification.md`。測試通過不代表臨床效能驗證。
