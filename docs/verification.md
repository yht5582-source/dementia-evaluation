# 驗證記錄

日期：2026-10-11。以下是程式及介面驗證，**不是臨床診斷效能驗證**。

## 功能

- 14 項純規則測試全部通過，涵蓋未知、安全警訊、快速進展、MCI 評估、功能下降、專業欄位隔離、混合線索及危險因子完整性。
- JavaScript 語法檢查通過。
- Codex 內建瀏覽器實際走過安全 → 認知功能 → 鑑別 → 危險因子 → 報告。
- 急性警訊時顯示立即評估，亞型判讀暫停；安全問題全否認後才顯示鑑別。
- 民眾與醫療模式切換正常；正式認知與其他原因評估僅醫療模式參與判讀。
- 風險清單及報告均有完整 14 因子；高 LDL 與未治療視力損失標示 2024 新增。
- 虛構紀錄下載 JSON 後清除，再匯入；認知摘要、LDL 狀態、自訂計畫、負責角色與日期均保留。
- 無效回答 JSON 被拒絕。帶 `<script>`／`<img onerror>` 的測試文字只顯示原文，不生成可執行元素。
- 390×844 視窗下，危險因子及報告頁的文件寬度與可見寬度一致（375 px，瀏覽器捲軸佔用 15 px）；頁面沒有水平溢出，寬表格在自身容器捲動。
- 瀏覽器主控台無警告或錯誤。
- 列印版面：1.1.1 以 Playwright（Chromium headless）用示例資料輸出 A4 PDF 並逐頁檢視（見下方）。不同瀏覽器的列印引擎仍可能略有差異，院內使用前請以實際印表機確認。

## 視覺檢查

使用內建瀏覽器，無 Playwright Chromium 替代。參考圖為 `design-concept.png`，桌面實作為 `desktop-preview.png`；兩者均以圖像檢視工具檢查。桌面視窗設為原始參考圖 1505×1045；瀏覽器捲軸占用使內容寬度為 1490，完整頁面截圖包含下方內容。

| 檢查點 | 實作及差異處理 |
|---|---|
| 架構 | 保留左側導航、頂部模式切換、步驟、安全主面板與右側說明 |
| 色彩 | 白底、深青側欄、青色選取與紅色安全面板；採純色減少裝飾 |
| 字體 | 保留清楚標題層級，問句／控制項有明確字級；系統中文字型依裝置呈現 |
| 控制項 | 三態選擇具有選取狀態與鍵盤焦點；所有按鈕是真實互動 |
| 內容 | 首屏標題、六項導航、模式名稱及下一步與設計對應 |
| 間距與行動版 | 桌面兩欄；行動版單欄、橫向導航及表格自身捲動 |

有意差異：安全檢核由參考圖三項增為四項以涵蓋快速進展；加入各問句提示、未知資料警告及版本／來源資訊。預設選民眾模式。圖示採一致線條圖示；不使用設計圖作為網站介面。實作符合參考圖的主要配置與視覺系統，並保留上述功能所需差異，不宣稱逐像素一致。

單檔 HTML 已檢查內嵌三段 JavaScript 語法。內建瀏覽器僅允許 HTTP／HTTPS，未直接驗證 file:// 開啟；一般瀏覽器離線開啟仍需使用者端確認。
